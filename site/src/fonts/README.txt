# Fonts

Self-hosted so the site looks the same on every device and makes no requests to font CDNs.

- **IBM Plex Sans**: 400, 400 italic, 500, 600, 700 (Copyright 2019 IBM Corp.)
- **IBM Plex Mono**: 400 (Copyright 2017 IBM Corp.)

Latin subset, WOFF2, taken unmodified from the Fontsource npm packages `@fontsource/ibm-plex-sans`
and `@fontsource/ibm-plex-mono` 5.3.0 (repackaging IBM's release). Licensed under the SIL Open Font
License 1.1; full text in `OFL.txt`. Declared in `../style.css`.
