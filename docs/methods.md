# Methods (stub — filled in during M2/M3)

Each estimand defined here must state: population, event definition, censoring rule,
estimator, uncertainty method, and known biases. See `docs/HANDOFF.md` §4 for the list.

1. Stage durations (dockets) — Kaplan–Meier by filing-year cohort; median/p75/p90; bootstrap CIs.
2. Age of pending cases — (a) docket cohorts; (b) Little's law W = L/λ from stock–flow tables
   (steady-state approximation; bias stated).
3. Reserve time (hearing → decision) — from decision headers; published written decisions only.
4. ONCA appeal duration — lower-court decision → hearing → decision; compare to ONCA annual report.
5. Criminal time to disposition (Ontario) — StatCan medians, Jordan-ceiling shares, OCJ panel.
6. Resource linkage — court × month panel: vacancies, complement, filings, delay measures.
7. Institutional-delay share (pilot) — s. 11(b) attribution extraction with validation set.
